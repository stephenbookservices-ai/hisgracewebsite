# His Grace and Power School website

Static site (HTML and CSS, no build step).

Files: index.html, images/logo.png, images/pupil.jpg, render.yaml

Deploy on Render: upload this folder to GitHub (index.html in the root), then New > Static Site, leave Build Command empty, Publish Directory `.`
Or New > Blueprint to use render.yaml.

Replace the pupil photo by overwriting images/pupil.jpg.
